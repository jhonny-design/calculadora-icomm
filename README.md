# Calculadora ICOMM

Precificação e margem para Mercado Livre, Shopee, TikTok Shop, Shein e Magalu.

- `index.html`: o site publicado (Vercel).
- `fonte/calculadora-artifact.html`: versão base da calculadora.
- `fonte/build_site.py` + `fonte/supa_block.js`: geram o `index.html` com login e banco (Supabase).
- `fonte/schema-supabase.sql`: estrutura do banco (tabelas, regras de acesso por conta).
